# Tietoturva

Jos löydät tietoturva-aukon (esim. tapa saada palvelin tallentamaan tai paljastamaan toisen käyttäjän tietoja),
**älä tee julkista ilmoitusta**. Ilmoita yksityisesti jommallakummalla tavalla:

1. **GitHub:** [Report a vulnerability](https://github.com/vilpponen/IBKR-yhteenveto/security/advisories/new)
   (näkyy vain ylläpitäjälle).
2. **Sähköposti:** info@arxsavonum.com

Kerro, mitä teit ja mitä tapahtui. Älä liitä oikeita IBKR-raportteja — keksityt tiedot riittävät.

Koskee sekä omalla koneella ajettavaa sovellusta että demoa osoitteessa https://ibkr.arxsavonum.com.

---

**English:** please report security issues privately via
[GitHub private vulnerability reporting](https://github.com/vilpponen/IBKR-yhteenveto/security/advisories/new)
or info@arxsavonum.com — not as a public issue. Do not attach real statements.
